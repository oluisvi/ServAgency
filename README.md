# ServAgency — Interactive Systems in Motion

A visual and interaction-led redesign of ServAgency built with Next.js, React and TypeScript.

## Current direction

- interactive editorial hero;
- per-letter kinetic typography;
- pointer-responsive signal sculpture using lightweight CSS 3D;
- parallax, fade/lift, stagger, clip reveal, magnetic CTAs and state transitions;
- compact horizontal project carousel with real project imagery;
- drag/touch/keyboard navigation and scroll-snap;
- reduced-motion and mobile re-art-direction;
- no added animation or WebGL dependency.

## Run

```bash
npm install
npm run dev
```

Validation before deployment:

```bash
npm run typecheck
npm run build
```
